# Respire

Cohérence cardiaque, simplement. Une PWA minimaliste : fond noir, une fleur qui respire avec toi.

**→ https://hrialan.github.io/respire/**

- Durée 3 / 5 / 10 / 15 min, rythme 5·5, 4·6, 4·4 ou personnalisé
- Vibration (Android ; retour haptique léger sur iPhone, iOS 18+) et son doux optionnel
- L'écran reste allumé pendant la séance, fonctionne hors ligne
- Toucher l'écran = pause · Espace = démarrer/pause · Échap = arrêter

**Installer sur mobile :** Safari → Partager → *Sur l'écran d'accueil* (iPhone), ou Chrome → *Installer l'application* (Android).

Zéro dépendance, zéro build : HTML, CSS et JS vanilla.

```sh
uv run python -m http.server 8000   # → http://localhost:8000
```
